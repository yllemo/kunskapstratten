Kunskapstratten Konceptet

Nuvarande funktioner · uppdaterad 31 augusti 2026

Från dokument till användbar kunskap

Kunskapstratten omvandlar dokument till en sökbar kunskapsbank i Markdown. Du väljer sedan vilka filer en chatt eller återanvändbar skill ska bearbeta. Den här sidan beskriver programmet; den är inte själva arbetsgränssnittet.

flowchart LR inbox["Inbox: dokument"] --> import["Import: MarkItDown + valfri AI"] import --> kb["Kunskapsbank: Markdown + YAML"] import --> archive["processed/: originalfiler"] kb --> selection["Du väljer underlag"] skills["Färdiga eller egna skills"] --> run["Chatt / skill-körning"] selection --> run memory["MEMORY.md"] --> run run --> save["Spara resultat till KB"] save --> kb

Import och bearbetning är separata steg. Importen skapar inga skills.

📁

Filer, inte databas

Markdown för innehåll och minne, JSON för importhistorik och GUI-inställningar. Inget vektorindex.

🧩

Du väljer uppgiften

Välj en skill och de .md-filer som ska ingå. Samma kunskapsbank kan bearbetas på flera sätt.

⚙️

Lokal AI som standard

Ollama på localhost:11434 med gemma4:26b. Byt server och modell i GUI:t.

🖥️

Desktop och mobil

Bläddra, ladda upp, redigera och chatta. Chatten använder hela höjden och har ett fast skrivfält.

🔒

Du styr var AI-anropen hamnar

Dokumenten lagras lokalt. Väljer du en extern AI-server skickas underlaget dit. Monaco, Mermaid och vissa resurser hämtas från CDN; helt offline är därför inte garanterat.

Arkitektur

Tydliga filer på disk

Kunskapsbanken är inte en SQL-databas. Dokument, original, skills och inställningar har varsin tydlig plats. Sökvägarna nedan är standardvärden.

  1. Inbox

    Ladda upp via GUI:t eller lägg filer direkt här. Importen tar hand om format som stöds av konverteraren.

    inbox/

  2. Konverterat innehåll

    Markdown med YAML-frontmatter, sökbar text och metadata. Bilder lagras i en separat undermapp.

    kunskapsbank/ · kunskapsbank/images/

  3. Originalarkiv

    Efter lyckad import flyttas originalfilen hit från inboxen. En importerad .md-fil är alltså fortfarande .md här; andra original behåller sina format.

    processed/

  4. Bearbetningsskills

    Återanvändbara instruktioner med namn och beskrivning, skapade manuellt eller medföljande som exempel. Oberoende av kunskapsbankens mappstruktur.

    skills/_custom/<slug>/SKILL.md

  5. Importregister

    Hash, status, källfil, resultatfil och tidsstämplar. Atomiska skrivningar och fillås skyddar uppdateringar.

    data/registry.json

  6. Inställningar och minne

    GUI-inställningarna överstyr config.yaml. Minnet är en vanlig Markdown-fil som alltid inkluderas i chatt och skill-körningar.

    data/settings.json · data/MEMORY.md

Befintlig historik följer med

En äldre registry.db läses vid första registeranvändningen och migreras till JSON. Originaldatabasen behålls som registry.db.bak. Stoppa gamla app- och watch-processer före uppgraderingen. SQLite används enbart för denna engångsmigrering.

Skills & underlag

En skill är en funktion – inte ett dokumentindex

Skillen beskriver vad AI:n ska göra. Du bestämmer vilka dokument den får arbeta med. Det finns ingen automatisk vektorsökning eller agent som själv hämtar relevanta filer i den här implementationen.

flowchart LR skill["Välj skill"] --> run["Kör bearbetningen"] docs["Välj KB-filer"] --> run memory["Gemensamt MEMORY.md"] --> run task["Valfri extra instruktion"] --> run run --> result["Granska resultat"] result --> save["Spara till KB om du vill"]

Sammanfatta

Medföljande skill för att sammanfatta valda dokument. Välj underlaget manuellt eller spara dokumentförval i skillen.

Fornnordisk pseudonymisering

AI letar efter namn och personuppgifter och ersätter dem med lekfulla fornnordiska namn.

Roligt exempel – inte säker anonymisering och inte för seriös produktion.

Skapa egna skills

Ange namn, beskrivning och instruktioner i GUI:t. Redigera sedan SKILL.md med Monaco, precis som dokumenten i kunskapsbanken.

🧩

Även direkt i chatten

Välj en skill i kontextpanelen eller kör vanlig chatt utan skill. Valda dokument, tillfälliga filer och minnet används som underlag. Separata skill-körningar kräver minst ett valt KB-dokument.

Ett medvetet avgränsat arbetssätt

Dokumentförval sparas i SKILL.md som en YAML-lista under document_paths, med sökvägar relativa till kunskapsbanken. Välj dem vid skapandet eller med Välj dokument på skills-sidan. När skillen väljs i chatten markeras dess dokument och körningen startar automatiskt. Utan förval används befintliga markeringar. Minne, historik och tillfälliga filer följer med. Saknade förvalda filer stoppar starten tills dokumentvalet rättats.

Manuellt dokumentval gör det tydligt vilket material som skickas till AI:n. Stora underlag måste fortfarande rymmas i modellens kontextfönster. Skills ersätter inte generell informationssökning; de ger återanvändbara instruktioner för bearbetningen.

Gränssnittet

Från uppladdning till sparat chattresultat

/browse

Bläddra och sök

Växla mellan kort, lista och tabell med 24, 48 eller 96 artiklar per sida. Sök i hela banken och filtrera på tagg eller filtyp. Taggar har artikelantal, egen sökning och högst 12 visas åt gången.

/upload · /new

Importera eller skriv nytt

Ladda upp dokument till inboxen, även flera åt gången, eller skapa ett Markdown-dokument direkt i kunskapsbanken.

/doc/… · /doc/…/edit

Läs och redigera

Formaterat YAML-frontmatter, Markdown och Mermaid-diagram. Monaco används för kodredigering, med textfält som reserv om editorn inte laddas.

/skills · /skills/new

Skapa och kör skills

Välj dokument inför körningen, granska strömmat resultat och spara det till KB. Import eller dokumentredigering skapar inga skills automatiskt.

/chat

Chatt med kontrollerad kontext

Välj KB-dokument, en skill och tillfälliga bilagor. Svaren strömmas och kan stoppas. Färdiga svar formateras som Markdown med Mermaid-diagram, utfällbar diagramkod och kopieringsknappar på kodblock. Dina meddelanden och AI-svar har skilda färger och avsändarmarkeringar.

Inställningar

AI, titel och minne

Byt modell eller visningstitel och redigera MEMORY.md i samma dialog. Inställningar sparas på disk utan att chatten behöver laddas om.

Chatten använder skärmytan

Den kompakta toppmenyn ger direkt åtkomst till tema, inställningar och hjälp. Övriga sidor samlas i en utfällbar meny på mindre skärmar. Hjälp öppnar den här guiden i en popup, i helskärm på mobil; stäng med krysset eller Escape.

Separata scrollområden

Sidopanel till vänster på desktop, med dokument, skill-val och kontextuppskattning. Konversationen fyller resten av höjden; skrivfältet ligger kvar längst ned.

Mobilpanel

På smal skärm öppnas sidopanelen via Kontext & skills. Navigering och inställningar finns i mobilmenyn.

Kontextmätare

Visar uppskattad användning för underlag, historik, skill och minne. Cirka fyra tecken per token, med varningsnivåer vid 75 och 90 procent.

📎

Tillfälliga filer är inte en import

Bilagor i chatten konverteras tillfälligt och läggs inte i inbox eller KB. Spara till KB exporterar själva konversationen som Markdown under kunskapsbank/chattar/. Bilagorna kopieras inte, men deras innehåll kan förekomma i svaren. Exportera före omladdning – chatten sparas inte automatiskt.

AI & minne

En gemensam konfiguration på lokal disk

Inställningarna är uppdelade i flikarna AI, Kunskapsbank, Minne och Återställ.

Dialogen har förval för Ollama, LM Studio och OpenAI-kompatibla tjänster. Hämta serverns modellista eller skriv ett modellnamn och testa anslutningen innan du sparar.

Server och modell

Bas-URL, API-nyckel, modell och aktivering av AI. Standard: Ollama på http://localhost:11434, modell gemma4:26b. API-klienten använder /v1.

Temperatur och systemprompt

Temperaturen används i chatt och skill-körningar. Chattens systemprompt kan anpassas; {context} infogar underlaget. Om markören saknas läggs kontexten till sist.

Kontextstorlek

Angivet tokenantal styr chattens uppskattning. Det ändrar inte serverns faktiska kontextstorlek. Standard är 32 768 tokens.

Kunskapsbankens titel

Visa exempelvis Demo1 i GUI:t. Projektet heter fortfarande Kunskapstratten och inga dokument, mappar eller register rensas.

  1. config.yaml: grundinställningar

    Mappar, importinställningar och grundvärden. Börja från config.example.yaml.

  2. data/settings.json: GUI-inställningar

    Överstyr grundvärden för AI och titel, även när CLI:t startas. Sparas på serverns lokala disk, inte i webbläsaren.

  3. data/MEMORY.md: gemensamt minne

    Redigeras manuellt i dialogen och inkluderas i chatt och skill-körningar. AI skriver inte automatiskt över minnet. Minnet räknas med i kontextuppskattningen.

🔑

Skydda lokala inställningar

API-nycklar lagras i klartext på disk, men returneras inte till webbläsaren. En sparad nyckel följer inte automatiskt med till en annan server. data/ är git-ignorerad. Dela inte inställningsfilen och exponera inte GUI:t publikt.

⚠

Återställning med två bekräftelser

En röd knapp kan permanent radera kunskapsbankens .md-filer och allt innehåll i skills, processed och data. Det omfattar även standard-skills, arkiverade original, minne och GUI-inställningar. Godkänn varningen, granska exakta mappar och filantal och lös sedan en mattefråga. Inbox, bilder/övriga KB-filer, loggar, programkod och config.yaml behålls. Ingen automatisk säkerhetskopia skapas. Stoppa andra app- och watch-processer och säkerhetskopiera först.

Praktiskt

Kom igång på fem steg

  1. 1

    Installera

    Python 3.10+. Skapa gärna en virtuell miljö och installera projektets beroenden.

    pip install -r requirements.txt
  2. 2

    Starta gränssnittet

    Kopiera config.example.yaml till config.yaml om du vill anpassa mappar. GUI:t startar som standard på http://127.0.0.1:5000.

    python run.py
  3. 3

    Välj AI och minne

    Starta din modellserver. Öppna Inställningar, välj modell och testa anslutningen. Spara önskad titel och innehållet i MEMORY.md.

  4. 4

    Ladda upp och bearbeta

    Ladda upp dokument till inboxen och klicka Uppdatera. Markdown hamnar i KB och originalen i processed/. Inga skills genereras.

  5. 5

    Välj underlag och arbeta

    Chatta eller kör en skill på valda dokument. Redigera Markdown med Monaco och spara önskade resultat tillbaka till KB.

↪

Efter uppgradering

Starta om appen för att läsa den nya koden. Äldre importhistorik migreras vid nästa registeranvändning, exempelvis med python run.py status. Säkerhetskopian behålls.
