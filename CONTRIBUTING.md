# Bidra

Tack för att du vill bidra.

1. Skapa en fork och en kortlivad feature branch.
2. Installera projektet enligt README och håll ändringen avgränsad.
3. Kör `python -m unittest discover -s tests -v`.
4. Kontrollera att inga dokument, loggar, databaser, API-nycklar eller lokala
   sökvägar har lagts till.
5. Beskriv beteendeförändringen och testningen i din pull request.

Använd svenska eller engelska i ärenden och pull requests. Genom att bidra
godkänner du att bidraget licensieras under projektets MIT-licens.
